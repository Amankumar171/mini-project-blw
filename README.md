# BLW Training Management Portal

A web-based Training Management System developed using Python, Flask, HTML, CSS, and SQLite.

## Features

- User Login System
- Attendance Management
- Notice Board Management
- Attendance Percentage Calculation
- Search and Date Filter
- CSV Report Download
- Secure Session Management

## Technologies Used

- HTML
- CSS
- Python 3.12
- Flask
- SQLite
- GitHub

## Live Website



## Run the Project

1. Install Python 3.12 and Flask: `py -3.12 -m pip install Flask==3.0.3`
2. Run `run_project.bat`, or execute `python app.py` from this folder.
3. Open http://localhost:5000/index.php

Default login: `aman` / `aman123`
